## Purpose

This repository serves as a collection of programming assignments and laboratory projects completed during university studies.

The projects cover fundamental C++ programming, Windows desktop development, networking and dynamic libraries.

## Development Environment

The projects are primarily designed for Microsoft Visual Studio on Windows.

Generated files and build artifacts such as `.vs`, `Debug`, `Release`, `x64`, `x86`, `bin` and `obj` are excluded from version control.
